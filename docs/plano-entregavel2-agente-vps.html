Componentes: (1) Sistematiza-Service FastAPI reusando o motor pronto; (2) Connectors com ingestão incremental por fonte; (3) Scheduler (cron/systemd + webhooks); (4) MCP server expondo as tools ao CC; (5) Storage central Supabase pgvector multi-tenant.

4. Segurança (Seção 11 — obrigatória)

  • API key server-side (bcrypt no banco), nunca no frontend/CC bundle.
  • CC ↔ VPS via proxy/Edge com JWT curto ou API key server-to-server.
  • Prompt-injection shield na ingestão (limite de chars, blocklist, log com hash).
  • Anti-bot + rate limit (Traefik); honeytoken /api/trap.
  • Docs sensíveis (jurídico) → backend LLM local na VPS (Ollama), sem sair da infra.
