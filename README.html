📚 Sistematiza

RAG poderoso sobre qualquer tema (sobre RAG-Anything) + organização jurídica de normas: hierarquia, vigência/revogação e estruturação automática de pastas — empacotado como plugin + agente Claude Code.

rag-anythinglightrag normasvigência/revogação plugin claude codeagente

Transforma documentos soltos em conhecimento organizado e consultável. No domínio jurídico é uma feature de 1ª classe: entende a hierarquia das fontes do direito (CF > LC > Lei > Decreto > Portaria), calcula vigência e revogação automaticamente (marcando a norma revogada e por qual norma) e organiza tudo em pastas por assunto/tipo/órgão/ano — da mais atual para a mais antiga.

Princípio-chave — lazy import: o subsistema normas/ é stdlib puro (Python 3.9+, sem RAG-Anything). Só ingest/query importam o motor pesado. Você organiza milhares de normas hoje, sem baixar 1 GB de modelos nem gastar token de API.

Instalação como plugin Claude Code

/plugin marketplace add ~/Projects/GitHub/sistematiza
/plugin install sistematiza@sistematiza-marketplace

Comandos: /sistematiza:new, /sistematiza:ingest, /sistematiza:query, /sistematiza:normas, /sistematiza:organize, /sistematiza:status. O agente sistematizador é acionado automaticamente.

Uso — modo jurídico (normas)

PY="python3 sistematiza/engine/sistematiza.py"
$PY init ./licitacoes --name "Licitações" --modo normas --backend ollama --storage local
$PY normas import ./licitacoes sistematiza/engine/tests/sample_normas.json
$PY normas organize ./licitacoes

Gera, em ./licitacoes/normas/: _INDICE.md (mais recente primeiro; ⛔ revogadas com a revogadora), _INDICE.json, acervo/<chave>.md, vigentes/, revogadas/, por-assunto/, por-tipo/, por-orgao/, por-ano/.

Exemplo de linha do índice mestre: 
- ⛔ Lei Ordinária nº 8.666/1993 — Regulamenta o art. 37, XXI... —
     REVOGADA por Lei Ordinária nº 14.133/2021 (2021)

Schema de uma Norma (registry.json)

CampoExemploNotas
tipo"lei_ordinaria"chave canônica ou texto livre
numero / ano"14.133" / 2021
data"2021-04-01"ISO 8601
orgao / esfera"Congresso Nacional" / "federal"
assuntos["licitações", ...]vira faceta por-assunto/
revoga["lei_ordinaria-8.666-1993"]referencia chaves <tipo>-<numero>-<ano>

Hierarquia (rank menor = mais alto): CF(1) · EC(2) · Tratado(3) · LC(4) · Lei/MP/Decreto-Lei(5) · Decreto(6) · IN/Resolução(7) · Portaria(8) · ...
Vigência (automática, bidirecional): declarar revoga na revogadora propaga revogada_por para a revogada.

Uso — modo genérico (RAG sobre qualquer tema)

$PY init ./pesquisa --modo generico --backend ollama --storage local
$PY ingest ./pesquisa ./meus-pdfs --recursive
$PY query  ./pesquisa "Qual a conclusão do estudo X?" --mode hybrid

Modos de query: naive · local · global · hybrid (recomendado) · mix · bypass.
